# 赛鸽科研中心

赛鸽科研中心（research.senopigeon.com）是 PigeonGene 数字生态的科研支撑站，收录**真实可追溯**的赛鸽科研文献与科学方法论。

## 本站原则

- **绝不伪造**：所有文献的 DOI、PubMed 均可追溯验证
- **科学严谨**：严格区分关联（Association）、相关（Correlation）、因果（Causation）与假说（Hypothesis）
- **诚实表述**：基因关联用"提示/可能关联"，不夸大结论

- [文献阅读指南](research/reading-literature.md) — 如何读懂科研论文

### 方法论

## 使用建议

- **鸽友**：从 [文献索引](papers/index.md) 的"通俗解读"入手，每篇论文都配有打比方式的讲解；
- **育种者**：关注 [证据分级](research/evidence-grading.md) 与 [文献阅读指南](research/reading-literature.md)，理解"关联≠因果"；
- **研究者**：直接使用各页面的 DOI/PubMed 链接溯源原文。
