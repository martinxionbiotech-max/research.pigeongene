# 研究方向

本站按 8 个方向组织赛鸽科研内容。每个方向页介绍研究背景、关键发现与文献来源，所有结论均标注证据边界。

## 研究方向

- [遗传学研究](genetics.md) — 赛鸽遗传学基础研究与候选基因分析（LDHA、DRD4、CRY1 等）。
- [性能研究](performance.md) — 飞行性能相关的遗传与生理研究，含候选基因关联证据。
- [归巢研究](homing.md) — 归巢与导航能力的遗传与行为研究。
- [耐力研究](endurance.md) — 长距离耐力表现的生理与遗传研究。
- [肌肉生理](muscle-physiology.md) — 肌肉发育与运动生理研究。
- [遗传标记](genetic-markers.md) — 遗传标记（SNP/微卫星）的识别与应用研究。
- [DNA 检测](dna-testing.md) — DNA 检测技术在赛鸽中的应用。
- [方法论](methodology.md) — 数量遗传学与分子检测方法。

## 阅读建议

- 涉及具体基因的结论，请对照 [证据分级](evidence-grading.md) 理解其强度；
- 引用文献前请通过 DOI/PubMed 链接核对原文，本站在 [文献索引](../papers/index.md) 提供可追溯出处；
- 所有研究结论均为关联性证据，不构成对个体成绩的预测。
